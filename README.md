**# Task 7: Build a Classification Model**



**## Project Overview**

**This project demonstrates student performance classification**

**using Python and Logistic Regression.**



**## Algorithm**

**Logistic Regression**



**## Input Features**

**- Age**

**- Department**



**## Target Categories**

**- High: Marks >= 85**

**- Low: Marks < 85**



**## Technologies Used**

**- Python**

**- Pandas**

**- Matplotlib**

**- Scikit-learn**



**## Methodology**

**1. Loaded and prepared the student dataset.**

**2. Created performance categories.**

**3. Selected input features and target labels.**

**4. Prepared numerical and categorical data.**

**5. Trained and evaluated the classifier using stratified**

&#x20;  **cross-validation.**

**6. Generated a classification report and confusion matrix.**



**## Outputs**

**- output/classification\_report.txt**

**- output/confusion\_matrix.png**



**## How to Run**

**Install the dependencies:**



**py -m pip install -r requirements.txt**



**Run the program:**



**py classification\_model.py**



**## Limitation**

**The dataset contains only a few student records.**

**Results are intended for educational demonstration and**

**should not be interpreted as reliable real-world predictions.**
